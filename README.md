# Convertivo

A free, offline unit converter for Windows.

## What it is

Convertivo is a desktop app that converts between units of measurement — length, area, volume, weight, time, speed, power, pressure, energy, digital storage, temperature, angles, and slope/grade. It runs entirely offline, so no internet connection is needed once it's downloaded.

It's built for anyone who regularly converts measurements: architects, drafters, engineers, contractors, tradespeople, and homeowners. You do not need any technical background to use it.

## Features

- Multiple categories: Length, Area, Volume, Weight/Mass, Time, Speed, Power, Pressure, Energy, Data storage, Temperature, Angle, and Slope/Grade
- Type a value into any unit field and every other unit on screen updates instantly — no separate "convert" button
- Feet-and-inches support, including fractional inches (e.g. 3' 4 1/2"), useful for construction and drafting work
- Side-by-side Imperial and Metric layout so you can compare both at a glance
- Search box to quickly filter down to the unit you need
- One-click copy button next to every result
- Light and dark display modes
- Works fully offline — no account, no internet connection required

## Installation / how to run

Convertivo does not require installation. It is a single file you run directly:

1. Download the `.exe` file from the [Releases page](../../releases).
2. Double-click the file to open the app.
3. Windows may show a security warning the first time — see below for what to do.

There is nothing to uninstall later beyond deleting the file.

## Windows Security Warning

When you run Convertivo for the first time, Windows may show a blue screen titled **"Windows protected your PC"**. This is expected, and it does not mean anything is wrong with the app.

This warning appears because Convertivo is not digitally "code-signed." Code-signing certificates cost money every year to maintain, and this app is provided free of charge, so it is not signed. Windows shows this same warning for any unsigned app, no matter how safe it is.

To open the app:

1. When you see the "Windows protected your PC" screen, click **More info** (small text, usually below the message).
2. A new line will appear showing the app name. Click the **Run anyway** button that appears underneath it.
3. The app will open normally. You will not be asked again on future launches of the same file.

If your antivirus software flags the file separately, you can add an exception for it. This is common for small independent apps that aren't yet widely recognized by antivirus vendors.
