# 🔄 Convertivo

### ⚡ A free, offline unit converter for Windows

---

## 📌 What it is

Convertivo is a desktop app that converts between units of measurement — length, area, volume, weight, time, speed, power, pressure, energy, digital storage, temperature, angles, and slope/grade.

💻 Runs entirely offline — no internet connection required.

🏗️ Built for architects, drafters, engineers, contractors, tradespeople, and homeowners.

---

## ✨ Features

- 📏 Multiple categories: Length, Area, Volume, Weight/Mass, Time, Speed, Power, Pressure, Energy, Data Storage, Temperature, Angle, and Slope/Grade
- ⚡ Type a value into any unit field and every other unit updates instantly
- 🏠 Feet-and-inches support, including fractional inches (e.g. 3' 4 1/2")
- 🔄 Side-by-side Imperial and Metric layout
- 🔍 Search box to quickly find the unit you need
- 📋 One-click copy button beside every result
- 🌙☀️ Light and dark display modes
- 🔒 Works fully offline — no account required

## 🚀 Installation / How to Run

Convertivo does not require installation.

1. ⬇️ Download the `.exe` file from the [Releases page](../../releases).
2. 🖱️ Double-click the file.
3. 🛡️ If Windows shows a security warning, follow the instructions below.

✅ That's it — no setup wizard, no installer, no admin rights required.

---

## 🛡️ Windows Security Warning

When you run Convertivo for the first time, Windows may show:

**"Windows protected your PC"**

This is expected and does **not** mean the application is unsafe.

ℹ️ The warning appears because Convertivo is not digitally code-signed. Code-signing certificates require ongoing annual costs, and this project is provided free of charge.

### To open the app:

1. Click **More info**
2. Click **Run anyway**
3. 🎉 Convertivo will launch normally
